{%- comment -%} A figure on a plate. Give `src` for an image that works on both themes, or `light` + `dark` for a theme pair. plate: "paper" keeps a white plate on both themes (plots drawn for white paper); "photo" removes the padding; "dense" is for figures with small labels: on phones they scroll sideways instead of shrinking. dense="1": the same sideways scrolling on phones, for a figure that also needs plate="paper" or the default plate. w, h: the pixel size of the image. Inside a .fig-row they set the width each figure gets, so that all plates in the row have one height. stage: for a single figure that is much narrower than the page. The plate spans the full row with this width-to-height ratio (for example stage="3") and the image is centered in it.
